# Pilot acceptance plan

## Usability sessions

Run moderated sessions with 3–5 students, two company representatives and one or two teachers. Do not use real applicant data. Ask each participant to complete the matching journey without guidance, then record task completion, time, errors and a 1–5 confidence score.

Acceptance targets:

- at least 80% complete their primary journey without intervention;
- all participants understand that matching does not make the final selection;
- no participant expects to see another student's score or rank;
- no critical accessibility or privacy issue remains open.

## Matching quality

For at least 20 fictional or consented profiles, ask a company representative to rate the Top 3 relevance from 1–5. Record false positives, missing candidates and proposed weight changes. Change weights only after the review set has been rerun and the rationale documented.

## Production readiness

- Choose and configure an email provider; keep the in-app notification as the source of truth.
- Add error monitoring and privacy-safe product analytics.
- Verify backups and restoration in the selected Supabase plan.
- Review the privacy notice, retention period, data-controller roles and user deletion process with OAMK.
- Run the security smoke suite against a non-production staging environment.
- Obtain named product-owner approval for the browser checklist and this pilot gate.
