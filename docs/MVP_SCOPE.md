## Pakollinen MVP

| Osa | Omistaja | Tila (backend) |
|-----|----------|----------------|
| Opiskelijaprofiili (CRUD API) | Tommi / Venla UI | API valmis |
| Projektit + harjoittelut (`opportunities`) | Tommi / Venla UI | API valmis |
| Projektien selaus + haku | Venla UI + GET API | API valmis |
| Hakeminen | Tommi / Venla UI | API valmis |
| Matching 0–100 + selitykset | Tommi | Valmis |
| Top-suositukset (`limit=3`) | Venla näyttää / API tukee | Valmis |
| Hakijat score-järjestyksessä | Tommi API + Venla UI | API valmis |
| Toimiva demo + seed | Shared | Seed olemassa |
| Raportti | Shared | Backend-osuus `docs/RAPORTTI_BACKEND.md` |

## Vapaaehtoinen / ei MVP

- Opinnäytetyöt erillisenä tyyppinä
- Maksut
- Chat
- Mobiilisovellus
- Ulkoinen AI-API matchingiin
- Automaattinen lopullinen valinta ilman ihmistä
- Oikea SMTP-sähköposti (MVP:ssä in-app + email-stub)
